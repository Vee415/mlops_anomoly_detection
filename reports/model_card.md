# Model Card — Sensor Anomaly Detection

## Model Details
- **Architecture:** Feed-forward neural network (FC classifier with BatchNorm + Dropout)
- **Input:** 4-dim feature vector (mean, std, peak, RMS from sliding windows)
- **Output:** 4-class probability distribution (Normal, Inner Race Fault, Outer Race Fault, Ball Fault)
- **Training framework:** PyTorch

## Intended Use
- **Primary:** Detect bearing faults from vibration/IMU sensor data in automotive/industrial applications
- **Out-of-scope:** Not intended for medical or safety-critical applications without additional validation

## Training Data
- Synthetic vibration data generated to mirror CWRU Bearing Dataset characteristics
- 4 classes: Normal, Inner Race Fault, Outer Race Fault, Ball Fault
- Sliding window feature extraction (window_size=128, stride=64)
- Z-score normalization using training set statistics

## Evaluation
- See `evaluation_report.md` for per-class precision/recall/F1
- Metrics auto-generated by `dvc repro` pipeline

## Limitations
- Trained on synthetic data; transfer to real CWRU data requires retraining
- Feature extraction discards temporal information beyond statistical aggregates
- Class distribution may not match real-world fault rates
