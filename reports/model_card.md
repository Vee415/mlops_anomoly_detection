# Model Card — Sensor Anomaly Detection

## Model Details
- **Architecture:** 1D-CNN (default) or feed-forward classifier, selectable via `model.arch` in `params.yaml`
- **CNN:** Conv1d→BN→ReLU→Pool→Conv1d→BN→ReLU→Pool→AdaptiveAvgPool→FC (default, 99.76% accuracy)
- **FC:** BatchNorm→Dropout→FC classifier on statistical features (91.77% accuracy)
- **Input:** Raw signal windows (CNN, shape N×1×128) or 4-dim feature vectors (FC)
- **Output:** 4-class probability distribution (Normal, Inner Race Fault, Outer Race Fault, Ball Fault)
- **Training framework:** PyTorch

## Intended Use
- **Primary:** Detect bearing faults from vibration/IMU sensor data in automotive/industrial applications
- **Out-of-scope:** Not intended for medical or safety-critical applications without additional validation

## Training Data
- Synthetic vibration data generated to mirror CWRU Bearing Dataset characteristics
- CWRU Bearing Dataset also supported via `data_source.type: cwru` in `params.yaml`
- 4 classes: Normal, Inner Race Fault, Outer Race Fault, Ball Fault
- Sliding window extraction (window_size=128, stride=64)
- Z-score normalization using training set statistics (FC only; CNN uses raw windows)

## Evaluation
- CNN (default): 99.76% test accuracy, 99.62% val accuracy
- FC: 91.77% test accuracy
- See `evaluation_report.md` for per-class precision/recall/F1
- Metrics auto-generated by `dvc repro` pipeline

## Limitations
- CNN trained on synthetic data; transfer to real CWRU data requires retraining
- FC model discards temporal information beyond statistical aggregates
- Class distribution may not match real-world fault rates
- Synthetic data may not capture all real-world noise patterns
